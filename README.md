# 눈으로 하는 디버깅 — 부스 진행 화면

## 실행

`index.html` 을 브라우저에서 열면 된다. 설치도, 서버도, 인터넷도 필요 없다.

부스에서는 크롬으로 열고 **F11**(맥은 `⌃⌘F`)로 전체화면을 켜두면 된다.
첫 화면의 `시작하기` 를 누를 때도 전체화면을 자동으로 시도한다.

## 진행 방법

1. **시작하기** 를 누른다
2. 참가자가 **초급 / 중급 / 고급** 중 하나를 고른다
3. 참가자가 준비되면 **시작하기** — 이 순간 문제와 타이머가 같이 시작된다
4. 제한시간(초급·중급 30초 / 고급 60초)이 끝나면 화면에 `시간 종료` 가 뜬다.
   정답은 저절로 나오지 않는다
5. **정답 보기** 를 누르면 틀린 줄이 강조되고 설명이 나온다.
   참가자가 일찍 맞히거나 포기했으면 시간이 남아도 눌러도 된다
6. **처음으로** 를 눌러 다음 참가자를 받는다

문제는 난이도별로 무작위로 나오되, 한 바퀴를 다 돌기 전에는 같은 문제가 다시
나오지 않는다. **페이지를 새로고침하면 이 기록이 초기화되므로**, 부스 운영 중에는
새로고침하지 말 것.

## 문제 추가·수정

문제는 난이도별 폴더에 JSON 파일 하나씩으로 들어 있다.

```
questions/
  easy/    01-array-index.json  02-assign-vs-equal.json  ...
  medium/  01-star-pattern.json  ...
  hard/    01-hanoi-base-case.json  ...
```

**난이도는 폴더가 정한다.** 문제를 초급에서 중급으로 옮기고 싶으면
파일을 `medium/` 으로 옮기기만 하면 된다.

### 순서

1. `questions/<난이도>/` 안에 JSON 파일을 새로 만들거나 고친다
   (기존 파일을 복사해서 내용만 바꾸는 게 가장 빠르다)
2. **`build.command` 를 더블클릭한다**
3. 브라우저에서 `index.html` 을 새로고침한다

2번을 빼먹으면 화면에 반영되지 않는다.
(`index.html` 은 `questions.js` 를 읽는데, 이건 `build.command` 가 JSON 들을
합쳐서 만드는 파일이다. 브라우저가 `file://` 에서 JSON 을 직접 못 읽어서 이렇게 한다.)

### JSON 형식

```json
{
  "prompt": "틀린 곳을 찾으세요",
  "lang": "C",
  "given": { "label": "원하는 출력", "text": "1 2 3 4 5" },
  "code": [
    "int arr[5] = {1, 2, 3, 4, 5};",
    "",
    "for (int i = 0; i <= 5; i++) {",
    "    printf(\"%d \", arr[i]);",
    "}"
  ],
  "bad": [3],
  "answer": "i <= 5   →   i < 5",
  "note": "크기가 5인 배열의 인덱스는 0부터 4까지다. arr[5]는 배열 밖을 읽는다."
}
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `prompt` | ○ | 문제 한 줄. `"틀린 곳을 찾으세요"` / `"출력 결과를 예측하세요"` |
| `lang` | | 코드블록 오른쪽 위에 뜨는 언어 이름. `"C"` `"C++"` `"Python"` |
| `given` | | 코드 위에 보여줄 조건. `label` 은 `"원하는 출력"` `"하는 일"` 등. `text` 는 여러 줄이면 배열로 |
| `code` | ○ | **한 줄이 배열 항목 하나.** 빈 줄은 `""` |
| `bad` | | 정답 공개 때 강조할 줄 번호. `code` 배열의 몇 번째인지를 **1부터** 센다 |
| `answer` | ○ | 정답 한 줄 |
| `note` | | 한 줄 설명 |

- 코드 안의 큰따옴표는 `\"`, 역슬래시는 `\\` 로 쓴다.
  `printf("\n");` 는 `"printf(\"\\n\");"` 가 된다 — JSON 규칙 그대로다
- `given.label` 에 한글 설명을 넣으면 본문 폰트로, 프로그램 출력이면 등폭 폰트로 알아서 나온다
- 글자 크기는 코드 길이에 맞춰 자동으로 줄어드니 신경 쓰지 않아도 된다

`build.command` 는 형식이 틀리면 어디가 왜 잘못됐는지 알려주고, **그럴 때는
`questions.js` 를 건드리지 않는다.** 고치고 다시 돌리면 된다.

## 파일

| 파일 | 내용 |
|---|---|
| `questions/` | **문제 원본. 보통 여기만 고치면 된다** |
| `build.command` | 더블클릭 → `questions/` 의 JSON 을 `questions.js` 로 합친다 |
| `index.html` | 슬라이드 4개의 뼈대 |
| `app.js` | 슬라이드 전환, 타이머, 문제 뽑기 |
| `style.css` | 화면 스타일 |
| `assets/logo.png` | 첫 화면 로고 (원본 `로고.png` 을 잘라 줄인 것) |
| `questions.js` | **자동 생성 파일. 직접 고치지 말 것** |
| `build.py` | `build.command` 가 실제로 실행하는 스크립트 |
